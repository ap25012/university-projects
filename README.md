# 🎓 Applied Informatics Master's Portfolio

Welcome to my academic portfolio! This repository contains a collection of projects, scripts, and technical reports completed during my Master's degree in Applied Informatics at Harokopio University.

Here is an overview of the main topics and projects included in this repository:

* **`ai`**: Machine Learning models, LLM API integrations, Prompt Engineering, and Autonomous Agents.
* **`cyber-security`**: Reports and assignments on network security and cryptography.
* **`database`**: SQL scripts, relational database design, and reports.
* **`database-budibase-docker`**: System integration and deployment using Budibase and Docker Compose.
* **`js`**: JavaScript assignments and scripts.
* **`python-project`**: Python applications and REST API integrations (e.g., Flask).
* **`redis`**: NoSQL database configurations and projects using Redis.

* **`statistical-analysis-with-python`**: Data analysis and statistical modeling using Python.
* **`system-analysis-and-design`**: UML diagrams, systems design, and software engineering methodologies.
* **`web-app`**: Web development assignments and applications.
* **`wireshark`**: Network traffic analysis and TCP/IP troubleshooting using Wireshark.

## 🤖 AI Experience (Application Question)

* **What I created:** I developed an autonomous ReAct AI Agent in Python that answers complex, multi-step queries by orchestrating custom tools (for structured data analysis) and a ChromaDB-powered RAG system (for semantic search).
* **The most interesting aspect:** The most fascinating part was designing the routing logic and watching the LLM (using OpenAI/Ollama APIs) dynamically reason and decide which tools to call to synthesize a final answer.
* **What it taught me:** This project gave me deep, hands-on understanding of prompt engineering (Zero/Few-shot, CoT), conversation memory management, and how to ground AI outputs in custom data to prevent hallucinations.
